## 1. 案別の違い（カレンダーのセル表現と開いたカード）

### 1a 線と余白（情報を削る）
- セル背景は白のまま。状態は **左 3px のライン**のみ（`over #2e7d32` / `under #c62828` / `attention #e65100`）。`cellSurface()` の 2 段階の濃淡（`#c8e6c9`/`#e8f5e9`、`#ffcdd2`/`#ffebee`）は撤去。
- セル内の値は **日 / 差分 / 出退勤 / 実働** の 4 つ。`miniTimeline()` と `休憩 x:xx` はセルから外し、ホバー（`title` ではなくツールチップ）に移す。
- 開いたカードは **2 ゾーン**（あと これだけ｜今月）。主役数字 40px → 52px。`renderProgressZone` は退勤後は元々空なのでそのまま。

### 1b 面で読む（色は1段階）
- 塗りは残すが **1 段階だけ**（`over: #e8f5e9 / border #a5d6a7`、`under: #ffebee / border #ef9a9a`）。`diff >= 1.5` の濃色分岐を削除。
- `miniTimeline` は **6px → 8px**、セルごとのガイド線（12/18/24時）をやめ、グリッド下に **時刻軸を1本だけ** 置く（5:00 / 12:00 / 18:00 / 翌5:00）。
- 開いたカードは **大きな数字3つ**（あと これだけ / 時間貯金 / 残業）＋着地の帯。`metricRow` + 細バーの積み上げを廃止。

### 1c 長さで読む（差分バー）
- セルは白＋薄い枠。過不足を **中央基準の差分バー**（高さ14px、中央線 `#cfd8d9`、±3:00 で振り切り＝`MINI_BAR_FULL_SCALE` を流用）で見せる。数値の色は緑/赤を維持。
- `miniTimeline`・`休憩`・塗りをすべて撤去（情報量は 3案中もっとも少ない）。
- 開いたカードは **左に主役数字（60px）／右に4行の一覧**（実績/必須・時間貯金・残業・着地）。

## 4. 確定（1a × 1c 混成）と実装手順

モックは `KOT見やすさ確定案.dc.html`（①基本形 ②勤務中 ③セルのホバー ④KOT の表を出した状態 ⑤1280px ⑥ダッシュボード）。

確定した選択:
- カレンダーのセル = 白背景＋**左 3px の状態ライン**（1a）＋**中央基準の差分バー**（1c）。塗り・セル内タイムライン・休憩表示は無し。
- **週合計列は既定で隠す**（C18）。ヘッダーの `▸ 週合計` で出す。
- **申請は日付の ▾ から**（C16）。セル内の `⋯` は廃止。
- セルから外した情報（稼働・休憩の帯 / 休憩の内訳 / 所定との差）は**ホバーのパネル**へ。

### 未決（設計の前に決めたいこと）
- 所定ラインは固定 8h（`DEFAULT_EXPECTED_HOURS`）で、シフトの `FIXED_WORK_MINUTE` ではない。シフト勤務の人には「届く/届かない」の基準がずれる。ホバーでは実働/所定を並べて出しているが、カード側の扱いは未決。
- ホバーパネルはタッチ環境で開けない。日付の ▾ を押したときに「申請 + 詳細」を両方出すかどうか。

## 6. 注意（モックの近似）

- セル内のミニタイムライン（1b）の休憩位置は、休憩の合計時間しか手元に無いため見た目の近似。実装では `buildTimelineSegments` の実データを使う。
- 1a/1c で外した「稼働・休憩の帯」「休憩 x:xx」はホバー表示に移す前提。ホバーの中身（ツールチップ）は方向が決まってから設計する。
