# Handoff: KotDiff 見やすさ改修（v2）

## Overview

KingOfTime（KOT）の月次勤怠画面に差分列とバナーを注入する Chrome / Firefox 拡張 **KotDiff** の UI 改修。
現状の問題は「どこに注目すべきか分からない」こと。具体的には次の 5 点。

1. 最重要指標（時間貯金）が他のテキストと同じ大きさで、視線の入口がない
2. 差分列が 28 列目（テーブル右端）にあり、横スクロールしないと見えない
3. 行頭の絵文字（カレンダー・お金・警告）が情報の階層を壊している
4. 赤・緑・黄が KOT 自身の土日色・スケジュール色と衝突し、色が意味を持っていない
5. ダッシュボードのサマリーカード 4 枚が完全に等価で、要注意情報（打刻漏れ）が埋もれる

改修の方針は **行動指向**。「何時間ズレているか」ではなく **「今日、何時に退勤すれば良いか」** を主役にし、
月全体は横棒 1 本とカレンダーで把握させる。統計的な予測は入れるが、**統計用語は画面に出さない**
（「10 回のうち 5 回」「短めの月／たぶん／長めの月」に翻訳する）。

## About the Design Files

このバンドルに含まれる HTML は **HTML で作った design reference（デザイン参照）** です。
意図した見た目と振る舞いを示すプロトタイプであり、そのままプロダクションコードとして
コピーするためのものではありません。

実装タスクは、**この HTML デザインを既存コードベース（kotdiff: TypeScript + React 19 + Tailwind CSS v4 +
Vite、Chrome MV3 / Firefox MV2）の中で、既存のパターン・ライブラリを使って再現すること**です。
KOT ページ側の注入 UI は React ではなく素の DOM 生成（`src/infrastructure/ui/*Renderer.ts`）である点に注意。
ダッシュボードは React + Tailwind（`src/dashboard/`）です。

## Fidelity

**High-fidelity (hifi)。** 色・タイポグラフィ・余白・行高はすべて確定値です。ピクセル単位で再現してください。
数値データはすべて実データ（`sample/normal/KING OF TIME 勤怠管理.html`、2026/02、勤務済み 13 日）から算出しています。
KOT ページ側の罫線・行高・フォント（Meiryo UI）・列幅は **既存 KOT の値を維持**すること。

デザインファイル内の ID と対応：

## Interactions & Behavior

- **注入カードの開閉**: ヘッダー行クリックでトグル。状態は `chrome.storage.local`（既存 `ChromeStorageAdapter`）に保存し、次回ロード時に復元。既定は「たたんだ状態」
- **カレンダーの開閉**: 見出しクリックでトグル。既定は「たたんだ状態」。状態も同様に保存
- **カレンダーのセルクリック**: ダッシュボードの日別テーブル該当行へスクロール（`scrollIntoView` は使わず `window.scrollTo` などで実装）＋ 行を 1 秒ハイライト
- **リアルタイム更新**: 勤務中は **30 秒間隔**で「経過 / 実労働 / あと / 退勤目安 / 本日バー」を再計算（既存 `PeriodicUpdateController` を利用）。休憩中は実労働を進めない（経過は最後の休憩開始で止める）
- **状態遷移**: 勤務中 → 休憩中 → 退勤後 → 非勤務日 で、注入カードの主役テキストが切り替わる（1-B 状態行の文言参照）
- **ホバー**: カレンダーセル・タイムライン帯にツールチップ（`稼働: 12:39 〜 23:30（8:30）` 形式。既存 `TimelineBar` のツールチップを流用）
- アニメーション: 既存 `dashboard/styles.css` の `chart-*` を維持。注入 UI の開閉は 120ms ease-out の高さトランジション程度に留める（`prefers-reduced-motion` で無効化）

## 計算ロジック（新規 `forecast.ts` として切り出す）

確定値（既存ロジックのまま。厳密に一意）
- 時間貯金 = Σ(実績 − 8h)（稼働日かつ実績あり）
- 残り必要 = 残稼働日 × 8h − 時間貯金
- 本日の必要 = 8h − 前日までの累積貯金（例: 8:00 − (−0:01) = 8:01）
- 退勤目安 = 出勤時刻 + 本日の必要 + 完了済み休憩（例: 11:07 + 8:01 + 1:06 = 20:14）
- 実労働（進行中）= (現在 − 出勤) − 完了済み休憩

推定値（新規。**画面には統計用語を出さない**）
- 勤務済み日の実績から 平均 `mean`、標本標準偏差 `sd`（n−1）
- 残り k 日の合計の予測: `mean * k ± t(0.90, n−1) * sd * √k * √(1 + 1/n)`（k=4、t=1.356、n=13 → ±4:46）
- 月末着地の点推定 = 実績 + 本日の予定 + `mean * k` → 144:00、80% 区間 139:14〜148:45
- 所定到達確率 → 「10 回のうち N 回」に変換して文字列化（今回は 5 回）
- 目標達成確度 80% にする 1 日あたり = `(残り必要 + t * se) / k` → 9:11
- 表示ルール: **点推定だけを大きく出さない**。必ず幅（帯）と同時に出す。σ / 予測区間 / 点推定 / n / df は画面に出さず、必要ならツールチップの注記に留める
